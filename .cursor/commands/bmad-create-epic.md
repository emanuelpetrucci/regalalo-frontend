# bmad-create-epic (v7)

En **BMad v7** no existe batch `bmad-create-story` sobre `sprint-status.yaml`.

## Qué hacer

1. Indicá la épica (ej. `14`, `epic-url-canonicalizacion-...`).
2. Usá skill **`bmad-agent-po`** para refinar/slicear, o editá:
   - `_bmad-output/initiative-regalalo/tickets/tickets.toml` (lista de épicas)
   - `_bmad-output/initiative-regalalo/tickets/epic-<slug>/tickets/tickets.toml` (entradas)
3. Referencia: `initiative-regalalo/archive-v6/epics.md`

Épica **14** (slugs/sitemap) ya está en el árbol de tickets; siguiente paso típico: **`bmad-build`** en **14-f3**.
